# 0.1.0 RC1 / Showcase release

2026-10-25。新的独立作品展示仓库，Windows ZIP保持原始发布候选字节不变。

## 可体验内容

正常探索与有限物资、钥匙与门锁、背包和统一工具箱、B对话、维尔遭遇与攻击、车辆维修和可完成的离镇流程。离场支持暂停、跳过、返回菜单及完成状态保存。

## 使用与限制

- 当前发行平台仅 Windows x64，使用 Forward+ / Vulkan。
- 不含自动全道具或自动修车。请正常搜索工具和物资。
- 初次启动可能准备着色器。最低配置尚未建立，其他硬件与多显示器场景仍需更多实测。
- 已有自动化覆盖并非连续人工通关记录；不以测试数量推导玩家体验或性能。
- 当前为开发中的 Demo，探索指引、交互手感和节奏仍可根据试玩反馈迭代。
- B 的双面图像属于已制作素材，SAN驱动双面切换未作为本版本功能交付。
