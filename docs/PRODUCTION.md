# 制作与素材说明

作者：吴坤昊 / KuuhhN。制作方式：个人主导、AI 辅助开发。

| 环节 | 个人负责 | 辅助方式 |
| --- | --- | --- |
| 玩法与范围 | 目标、需求拆解、取舍、反馈与验收 | Codex 协助梳理实现与边界 |
| 开发 | 交互要求、问题复现、版本比较和集成验证 | Codex 辅助 GDScript 与程序化建模/场景 |
| 角色与道具 | 风格参考、候选比较、筛选与运行效果判断 | AI 图像生成、像素化与资源接入 |
| 展示 | 项目方向与内容选择 | 文档排版、实机定帧拍摄与剪辑 |

宣传片时长约70秒，1920×1080，30fps。游戏实机原素材1280×720，以最近邻缩放保留像素观感。昼夜探索、人物与室内镜头取自同项目开发期原始实机录像；2026-10-25从本次发布ZIP解压的EXE补录车辆检查及离场。拍摄使用隔离存档和位置/状态布置，动作来自游戏逻辑，未使用生成式视频或补帧。

影片原始轨道被统一替换为本地数学合成氛围配乐，无外购音乐及旧TTS语音。字幕、片头片尾为剪辑包装，非游戏UI。

图册中的画面分别标明实机、角色/道具资产与历史迭代。历史废案只用于说明选择过程，不暗示全部纳入当前Demo。

相关第三方素材与字体许可见仓库根目录 THIRD_PARTY_NOTICES.md。公开展示材料不包含简历中的私人联系电话与邮箱。
